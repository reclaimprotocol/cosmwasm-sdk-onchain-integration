# Reclaim Protocol - CosmWasm Smart Contract

A CosmWasm smart contract implementation of the [Reclaim Protocol](https://www.reclaimprotocol.org/) for verifying zero-knowledge proofs on-chain. This contract enables decentralized verification of claims signed by Reclaim witnesses on CosmWasm-compatible blockchains.

## Overview

This contract allows users to:
- **Verify Proofs**: Submit and verify cryptographic proofs generated by Reclaim Protocol
- **Manage Epochs**: Configure witness sets and minimum witness requirements for claim verification
- **Query State**: Retrieve epoch configurations and witness information

The contract supports two build targets:
- **Vanilla CosmWasm** - For standard CosmWasm chains (e.g., Nibiru)
- **Secret Network** - With privacy-preserving features

## Prerequisites

- [Rust](https://rustup.rs/) (latest stable)
- `wasm32-unknown-unknown` target: `rustup target add wasm32-unknown-unknown`
- (Optional) Rust nightly for tests: `rustup install nightly`

## Building

Build for vanilla CosmWasm chains (Nibiru, etc.):

```bash
make vanilla
```

Build for Secret Network:

```bash
make secret
```

Both commands produce:
- `reclaim_cosmwasm.wasm` - The compiled contract
- `reclaim_cosmwasm.wasm.gz` - Compressed for deployment

## Testing

make test

## Contract Interface

### Instantiate

```json
{
  "owner": "<address>"
}
```

### Execute Messages

**VerifyProof** - Verify a Reclaim proof on-chain:

```json
{
  "verify_proof": {
    "proof": {
      "claim_info": {
        "provider": "<provider_id>",
        "parameters": "<parameters_json>",
        "context": "<context>"
      },
      "signed_claim": {
        "claim": {
          "identifier": "<claim_hash>",
          "owner": "<owner_address>",
          "epoch": 1,
          "timestamp_s": 1234567890
        },
        "signatures": ["<sig1>", "<sig2>"]
      }
    }
  }
}
```

**AddEpoch** - Add a new epoch with witnesses (owner only):

```json
{
  "add_epoch": {
    "witness": [
      { "address": "0x...", "host": "witness.example.com" }
    ],
    "minimum_witness": "1"
  }
}
```

### Query Messages

**GetEpoch** - Get a specific epoch:

```json
{ "get_epoch": { "id": 1 } }
```

**GetAllEpoch** - List all epoch IDs (vanilla only):

```json
{ "get_all_epoch": {} }
```

## How It Works

1. **Epoch Configuration**: The contract owner configures epochs with a set of authorized witnesses and minimum witness requirements
2. **Proof Generation**: Users generate proofs off-chain using Reclaim Protocol SDKs
3. **On-chain Verification**: The contract verifies that:
   - The claim hash matches the provided claim info
   - Signatures are from authorized witnesses for the epoch
   - The minimum witness threshold is met
4. **Events**: Successful verification emits events with signer information
